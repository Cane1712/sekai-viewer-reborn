Show Kizuna titles the way players can set them in the game. The Titles catalogue's Kizuna dialog gets display options that apply to every rarity: the word (the pair's default words and unlockable words, with each word's unlock condition), a Swap sides switch (the game's reverse view types), and, for a unit member with a Virtual Singer, the Virtual Singer's outfit: their own, or the partner's unit outfit (the `*_unit_virtual_singer` view types, drawn with that unit's character art, for example Leo/need Miku). Each pair opens with the defaults, and the catalogue cards keep them.
